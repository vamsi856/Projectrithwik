# Rithwik website

Animated one-page site for **Rithwik Bird Feeds** and **Rithwik Industries** (Kurnool, Andhra Pradesh), a client project.
Live at https://vamsi856.github.io/Projectrithwik/ (GitHub Pages, served from the root of `main`).

## Layout

- `site/` is the source: an Astro 5 static site (GSAP + ScrollTrigger, Lenis, three.js for the 3D packs).
- The repo root (`index.html`, `_astro/`, `img/`, `birds/` …) is **generated**: `npm run build` builds `site/dist`
  and `site/scripts/publish.mjs` copies it to the root. Never edit root files by hand.
- One page, three views: the "book" cover, `#bird-feeds` and `#human-food` (Rithwik Industries).

## Commands (run in `site/`)

```
npm install
npm run dev                                   # http://localhost:4321/Projectrithwik/
npm run build                                 # builds and copies to the repo root
npx astro preview --port 4331                 # serve the build
node scripts/check-sizes.cjs                  # 13 widths x 3 views: no sideways spill, header OK
python3 scripts/make_photos.py                # photo sizes (pip install pillow pillow-heif)
```

Deploy = build, commit `site/` **and** the regenerated root files, push to `main`. Pages redeploys in about a minute.
If a push doesn't trigger Pages, push an empty commit.

## Where things are

- `site/src/data/products.ts`: every product, its variants (crop/colour options), photos, swatches, and `CONTACT`
  (phones, WhatsApp, emails, office and warehouse map links).
- `site/src/data/commons.json`: photo registry. Client photos have `own: true` and `local: 'photos/<key>.webp'`.
  Stock photos carry their Wikimedia credit, which the "Photo credits" panel lists.
- `site/src/data/photo-sizes.json`: generated by `make_photos.py`. Don't edit.
- `site/src/data/legacy.ts`: the family timeline 1925 to 2022 and `FOUNDERS` (round photo on the 2022 dot).
- `site/src/data/perches.ts`: the real birds that hop onto product cards.
- `site/src/scripts/main.ts`: page behaviour and animation (views, menus, paper birds, map tabs, forms, sound button).
  `flock.ts` is the hero macaw flock, `sound.ts` the birdsong and flute, `pack3d.ts` the 3D packs.
- `site/src/styles/v2.css`: all styles. Components are in `site/src/components/`.

## Adding a client photo

1. Crop it from the original: 4:3, **grain only, no hands or background**, at least ~800px wide if possible.
2. Save it as `site/photo-src/<key>-rithwik.webp`.
3. Add `"<key>-rithwik": {"t": "<name>", "u": "", "w": W, "h": H, "p": "", "l": "", "a": "Rithwik", "local": "photos/<key>-rithwik.webp", "own": true}` to `commons.json`.
4. Point the product (`photo: '...'`) or a single variant (`{ label: 'Red', gst: '0%', photo: '...' }`) at it in `products.ts`.
5. Run `python3 scripts/make_photos.py`, then build. To replace a photo, delete `public/img/<key>-*` first
   (the script never overwrites). When a stock photo is no longer used, remove it from `commons.json`,
   `photo-sizes.json` and `public/img`, so the credits stay accurate.
