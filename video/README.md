# Rithwik ad (TV and web)

A 60-second ad made from the website itself: the address typed into a browser, the book opening, Bird Feeds (the
macaws, Who we are, the family timeline, packs, birds, feeds, the India map, certifications), a circle into Rithwik
Industries (hero, facts, packs, the range), and an end card with the phone number and the website.

Two soundtracks, same picture:

- **Birdsong**: the site's own sound. Soft dawn chorus over the browser and the book, full birdsong as Bird Feeds
  opens, the page-turn sound, then the site's calm Human Food music (tanpura drone, raga Mohanam) to the end.
- **Calm**: one plain, calm piece all the way through (soft pad, felt piano, bass, D major).

Files (in `out/Rithwik-Ad/`, not in git): `Rithwik-Ad-4K-Birdsong.mp4`, `Rithwik-Ad-4K-Calm.mp4` (3840x2160) and
`Rithwik-Ad-1080p-Birdsong.mp4`, `Rithwik-Ad-1080p-Calm.mp4` (1920x1080). 25 fps (the Indian TV standard),
H.264 + AAC 48 kHz, sound at -16 LUFS. A channel that asks for EBU R128 (-24 LKFS) gets it with
`node render.mjs --lufs -24`.

## Making it again (after the site changes)

```
cd site && npx astro build          # the site to record
cd ../video && npm install
node capture/record.cjs             # records the three clips in 4K (about 10 minutes)
node audio/make-music.cjs           # renders the music and sounds
node render.mjs                     # the four finished files (about 30 to 60 minutes)
```

- `capture/record.cjs`: what is recorded. Each clip is one page load; its segments say where the page is scrolled
  and for how long. `capture/clock.js` is the frame-by-frame clock that keeps every animation smooth.
- `src/timeline.ts`: the edit (which segments, in what order, how long, the captions and the transitions).
  `src/scenes.tsx`: the browser opening, the shots and the end card. `src/Ad.tsx`: the two soundtracks.
- `npx remotion studio` opens the edit in a browser to look through it; `node stills.mjs 300 900` renders single
  frames to `out/stills/`.
